企业级 CI/CD 自动化部署工具

一键部署，多语言支持，让复杂的容器化部署变得简单高效。 支持Java、Python、Vue.js、Go等主流技术栈，完美集成Kubernetes和Docker Swarm。

🚀 快速开始 📚 查看文档

三步快速开始

从安装到部署，只需要三个简单步骤

1

安装 DevOps

选择安装方式，自动配置所需环境

curl -fsSL https://github.com/edisonlil/devops/raw/refs/heads/dev/install.sh | bash
1. 下载代码
git clone -b dev https://github.com/edisonlil/devops.git
2. 执行安装
cd devops && chmod +x install.sh && ./install.sh --offline
2

创建工作空间

配置项目工作空间，隔离不同项目环境

devops create workspace demo -i
→
3

一键部署

从代码拉取到容器化部署，一条命令搞定

devops run java --git-url https://github.com/example/app.git my-app

核心功能

为现代化应用部署而生的强大功能

🎯

交互式部署

引导式配置流程，新手也能快速上手。智能显示默认值，逐步提示输入参数，实时验证配置有效性。

🔧

多语言支持

支持Java、Python、Vue.js、Go、Nginx、Tomcat等主流技术栈。自动识别项目类型，选择最佳构建策略。

🌐

多端口配置

灵活的多端口配置系统，支持命名端口、智能映射。完美适配微服务架构的复杂端口需求。

📦

模板系统

两级模板系统，支持全局和workspace级别模板。团队可以定制专属模板，提高部署标准化程度。

⚙️

版本管理

独立的构建工具版本管理，支持nvm、sdkman等多种版本管理器。确保团队环境一致性。

☸️

企业级集成

完整的Harbor镜像仓库集成，Kubernetes原生支持。支持远程部署，完美适配企业级CI/CD流程。

使用示例

看看如何使用 DevOps 快速部署不同类型的应用

Java Spring Boot 应用

devops run java --git-url https://github.com/example/spring-app.git --build-tool maven my-app

自动从Git拉取代码，Maven构建，Docker镜像打包，部署到Kubernetes

Vue.js 前端应用

devops run vue --git-url https://github.com/example/vue-app.git --build-env prod my-frontend

npm安装依赖，构建生产环境静态资源，Nginx容器化部署

Go 微服务应用

devops run go --git-url https://github.com/example/go-api.git my-api

Go模块依赖管理，静态编译，轻量级容器镜像构建

Python Flask/Django 应用

devops run python --git-url https://github.com/example/flask-app.git --python-main app.py my-python-app

pip依赖安装，虚拟环境管理，WSGI服务器容器化部署
