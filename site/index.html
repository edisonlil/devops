企业级 CI/CD 自动化部署工具

一键部署，多语言支持，让复杂的容器化部署变得简单高效。 支持Java、Vue.js、Go等主流技术栈，完美集成Kubernetes和Docker Swarm。

三步快速开始

从安装到部署，只需要三个简单步骤

1

安装 DevOps

一行命令完成安装，自动配置所需环境

curl -fsSL https://github.com/edisonlil/devops/raw/refs/heads/dev/install.sh | bash
→
2

创建工作空间

配置项目工作空间，隔离不同项目环境

devops create workspace demo -i
→
3

一键部署

从代码拉取到容器化部署，一条命令搞定

devops run java my-app --git-url https://github.com/example/app.git

核心功能

为现代化应用部署而生的强大功能

🎯

交互式部署

引导式配置流程，新手也能快速上手。智能显示默认值，逐步提示输入参数，实时验证配置有效性。

🔧

多语言支持

支持Java、Vue.js、Go、Nginx、Tomcat等主流技术栈。自动识别项目类型，选择最佳构建策略。

🌐

多端口配置

灵活的多端口配置系统，支持命名端口、智能映射。完美适配微服务架构的复杂端口需求。

📦

模板系统

两级模板系统，支持全局和workspace级别模板。团队可以定制专属模板，提高部署标准化程度。

⚙️

版本管理

独立的构建工具版本管理，支持nvm、sdkman等多种版本管理器。确保团队环境一致性。

☸️

企业级集成

完整的Harbor镜像仓库集成，Kubernetes原生支持。支持远程部署，完美适配企业级CI/CD流程。

使用示例

看看如何使用 DevOps 快速部署不同类型的应用

Java Spring Boot 应用部署

从Git仓库拉取代码，自动构建并部署到Kubernetes

devops run java my-app \
--git-url https://github.com/example/spring-app.git \
--build-tool maven \
--app-port 8080 \
--expose-port 30080
部署结果：
  • ✅ 自动从Git拉取最新代码
  • ✅ Maven自动构建JAR包
  • ✅ Docker镜像构建和推送
  • ✅ 部署到Kubernetes集群

Vue.js 前端应用部署

自动化构建Vue项目并部署到容器平台

devops run vue my-frontend \
--git-url https://github.com/example/vue-app.git \
--build-env prod \
--expose-port 30081
部署结果：
  • ✅ npm install安装依赖
  • ✅ 构建生产环境静态资源
  • ✅ Nginx容器化部署
  • ✅ 自动配置路由规则

Go 应用部署

Go应用的快速构建和容器化部署

devops run go my-api \
--git-url https://github.com/example/go-api.git \
--app-port 8080
部署结果：
  • ✅ Go模块依赖管理
  • ✅ 静态编译二进制文件
  • ✅ 轻量级容器镜像
  • ✅ 高性能服务部署
