场景演示

看看如何使用 DevOps 工具快速部署不同类型的应用

Java Spring Boot 应用部署

使用 DevOps 工具一键部署 Java 应用到容器平台

自动化部署完成
✅ 自动从 Git 拉取最新代码
✅ Maven/Gradle 自动构建 JAR 包
✅ Docker 镜像构建和推送
✅ 部署到 Docker Swarm/Kubernetes
1
配置工作空间
设置项目工作空间和环境
devops --workspace myproject
2
Maven 项目部署
从 Git 仓库拉取代码并自动构建部署
devops run java --git-url https://github.com/springframeworkguru/helloworld.git --build-tool maven hello-world
3
Gradle 项目部署
支持 Gradle 构建工具和自定义 JVM 参数
devops run java --git-url http://example.com/sample.git --build-tool gradle --java-opts "--profile=prod" sample

Vue.js 前端应用部署

使用 DevOps 工具自动化部署 Vue.js 前端项目

自动化部署完成
✅ 自动从 Git/SVN 拉取最新代码
✅ npm install 安装依赖
✅ 构建并生成生产环境静态资源
✅ Docker 镜像构建与部署
1
基础 Vue 项目部署
从 Git 仓库部署 Vue 项目，自动 npm 构建
devops run vue --git-url http://example.com/vue-project.git --dockerfile node --template node sample
2
多环境构建部署
支持不同环境的构建配置（dev/test/prod）
devops run vue --git-url http://example.com/vue-project.git --build-env "prod" --dockerfile node sample
3
自定义构建命令
使用自定义构建命令和 SVN 代码仓库
devops run vue --svn-url https://example.com/svn/vue-project --build-cmds "npm run build:test" sample

支持 Ubuntu、CentOS、RHEL、Debian、Fedora
