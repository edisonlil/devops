# 版本管理功能

DevOps 支持灵活的构建工具版本管理，让您可以为不同项目指定不同的工具版本，确保构建环境的一致性。

## 🎯 核心特性

- **独立版本管理**: `--build-version` 专门管理构建工具版本
- **多级配置**: 支持命令行和workspace两级版本配置
- **智能优先级**: 命令行参数自动覆盖workspace配置
- **多工具支持**: 支持 Node.js、Java、Maven、Gradle、Volta、Python 等

## 📋 支持的版本管理器

| 工具 | 版本管理器 | 示例 |
|------|------------|------|
| Node.js | nvm, fnm, n, volta | `node:18.12` |
| Java | sdkman | `jdk:17`, `java:11` |
| Maven | sdkman | `maven:3.9.3` |
| Gradle | sdkman | `gradle:8.0` |
| Volta | volta | `volta:18.12` |
| Python | conda, pyenv | `python:3.11`, `py:3.10` |

## 🔧 使用方法

### 基本语法

```bash
# 单个工具版本
devops run <type> <name> --build-version "工具:版本"

# 多个工具版本
devops run <type> <name> --build-version "工具1:版本1,工具2:版本2"
```

### 实际示例

```bash
# Vue项目指定Node.js版本
devops run vue my-app --build-version "node:18.12"

# Java项目指定JDK和Maven版本
devops run java my-app --build-version "jdk:17,maven:3.9.3"

# 使用Volta管理Node.js
devops run vue my-app --build-version "volta:18.12"

# Python项目指定Python版本
devops run python my-api --build-version "python:3.11"

# 混合版本配置
devops run java full-stack --build-version "node:18.12,jdk:17,maven:3.9.3"
```

## 🏢 Workspace版本配置

### 配置方式

在workspace配置文件中设置默认版本：

```bash
# 编辑 workspace/{name}/config
BUILD_VERSION="node:18.12,jdk:17,maven:3.9.3"
```

### 创建时配置

```bash
# 非交互式创建
devops create workspace demo --build-version "node:18.12,jdk:17"

# 交互式创建（会提示输入版本配置）
devops create workspace demo -i
```

### 优先级规则

1. **命令行参数** (`--build-version`) - 最高优先级
2. **Workspace配置** (`BUILD_VERSION`) - 默认版本
3. **无版本配置** - 使用系统默认版本

## 📝 版本格式说明

### Node.js版本格式

```bash
node:18.12    # 具体版本
node:18       # 主版本
node:lts      # LTS版本
volta:18.12   # 通过Volta管理
```

### Java版本格式

```bash
jdk:17        # JDK 17
java:17       # Java 17 (与jdk:17相同)
jdk:11        # JDK 11
```

### Maven/Gradle版本格式

```bash
maven:3.9.3   # Maven具体版本
maven:3.8     # Maven主版本
gradle:8.0    # Gradle具体版本
```

## 🔄 版本切换流程

1. **解析版本配置**: 解析 `--build-version` 参数或workspace配置
2. **验证版本管理器**: 检查对应的版本管理器是否安装
3. **切换版本**: 调用相应的版本管理器切换版本
4. **验证切换**: 确认版本切换成功
5. **执行构建**: 使用指定版本进行构建

## 💡 最佳实践

### 团队协作

```bash
# 在workspace中配置团队标准版本
BUILD_VERSION="node:18.12,jdk:17,maven:3.9.3"

# 团队成员使用时自动应用标准版本
devops run java my-project  # 自动使用workspace配置的版本
```

### 项目特定版本

```bash
# 为特定项目覆盖workspace配置
devops run vue legacy-project --build-version "node:16.14"
```

### 环境一致性

```bash
# 开发环境
devops run java my-app --build-version "jdk:17,maven:3.9.3" --build-env "dev"

# 生产环境（使用相同版本）
devops run java my-app --build-version "jdk:17,maven:3.9.3" --build-env "prod"
```

## 🛠️ 故障排除

### 常见问题

**版本管理器未安装**
```bash
# 错误信息
ERROR: nvm not found, please install nvm first

# 解决方案
devops install-tools --tools nvm
```

**版本不存在**
```bash
# 错误信息
ERROR: Node.js version 18.12 not available

# 解决方案
nvm install 18.12
```

**权限问题**
```bash
# 错误信息
ERROR: Permission denied when switching version

# 解决方案
# 确保版本管理器正确安装并配置环境变量
```

### 调试技巧

```bash
# 查看当前版本
node --version
java -version
mvn --version

# 查看可用版本
nvm list
sdk list java
```
