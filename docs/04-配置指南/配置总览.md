## 🎯 配置优先级

DevOps 使用分层配置系统，优先级从高到低：

1. **命令行参数** - 最高优先级
2. **Workspace配置** - 项目/团队级别配置
3. **全局默认值** - 系统默认配置

### 示例

```bash
# 命令行参数覆盖workspace配置
devops run java app --build-version "jdk:11" --build-env "prod"

# 使用workspace默认配置
devops run java app  # 自动使用workspace中的BUILD_VERSION
```

## 🔄 配置方式

### 1. 命令行配置

```bash
# 直接通过命令行参数配置
devops run java app \
  --git-url https://github.com/user/repo.git \
  --build-version "jdk:17,maven:3.9.3" \
  --service-port "http:8080,admin:9090" \
  --export-port "30080,30090"
```

### 2. 交互式配置

```bash
# 启动交互式配置
devops run java app -i

# 系统会引导用户逐步配置所有参数
```

### 3. Workspace配置

```bash
# 编辑workspace配置文件
vim workspace/my-team/config

# 配置示例
BUILD_VERSION="jdk:17,maven:3.9.3"
BUILD_GIT_URL="https://git.company.com"
BUILD_HARBOR_ADDRESS="harbor.company.com"
```

## 📝 常用配置模式

### 开发环境配置

```bash
# 开发环境通常使用较新的版本和调试配置
devops run java dev-app \
  --build-version "jdk:17,maven:3.9.3" \
  --build-env "dev" \
  --service-port "8080,9090" \
  --namespace "dev"
```

### 生产环境配置

```bash
# 生产环境使用稳定版本和优化配置
devops run java prod-app \
  --build-version "jdk:11,maven:3.8.6" \
  --build-env "prod" \
  --service-port "http:8080" \
  --export-port "30080" \
  --namespace "production"
```

### 团队标准化配置

```bash
# 在workspace中配置团队标准
# workspace/team/config
BUILD_VERSION="jdk:17,maven:3.9.3"
BUILD_HARBOR_ADDRESS="harbor.company.com"
BUILD_HARBOR_PROJECT="team-project"
BUILD_GIT_BRANCH="main"

# 团队成员使用时自动应用标准配置
devops run java my-project  # 自动使用团队标准配置
```

## 🛠️ 配置验证

### 配置检查

```bash
# 查看当前workspace配置
devops env info

# 验证配置有效性
devops validate config
```

### 配置调试

```bash
# 显示最终生效的配置
devops run java app --dry-run

# 查看配置来源
devops run java app --show-config
```

## 💡 最佳实践

### 1. 分层配置策略

```bash
# 全局默认值 -> Workspace配置 -> 命令行参数
# 每一层只配置该层关心的参数
```

### 2. 环境隔离

```bash
# 不同环境使用不同的workspace
devops create workspace dev-env --namespace dev
devops create workspace prod-env --namespace production
```

### 3. 版本锁定

```bash
# 在workspace中锁定稳定版本
BUILD_VERSION="jdk:11.0.19,maven:3.8.6"

# 避免使用浮动版本如 "jdk:11" 或 "maven:3"
```

### 4. 配置文档化

```bash
# 在workspace中添加配置说明
# workspace/team/README.md
# 说明各配置项的用途和修改影响
```
