# 快捷键管理功能

DevOps 快捷键功能允许您将复杂的部署命令保存为简短的快捷键，方便团队共享和快速调用。

## 🎯 核心特性

- **命令简化**: 将复杂的部署命令保存为简短的快捷键
- **团队共享**: 快捷键存储在工作空间中，团队成员共享
- **参数覆盖**: 执行时可以覆盖部分参数
- **安全确认**: 生产环境相关的快捷键会要求确认
- **预览模式**: 支持预览模式，查看将要执行的命令

## 📋 基本用法

### 保存快捷键

```bash
# 基本语法
devops shortcut save <快捷键名称> <命令...>

# 保存生产部署命令
devops shortcut save prod-deploy \
  devops run java my-app \
  --git-url https://github.com/company/my-app.git \
  --git-branch release \
  --build-version "jdk:11,maven:3.8.6" \
  --build-env prod \
  --service-port "8080" \
  --export-port "30080" \
  --namespace production

# 带描述和标签保存
devops shortcut save microservice-deploy \
  devops run java user-service \
  --service-port "http:8080,admin:9090" \
  --export-port "30080,30090" \
  --namespace microservices \
  --description "微服务部署命令" \
  --tags "microservice,production"
```

### 执行快捷键

```bash
# 直接执行快捷键
devops prod-deploy

# 或使用完整命令
devops shortcut run prod-deploy

# 覆盖部分参数
devops prod-deploy --override --git-branch hotfix/urgent-fix

# 预览模式（不实际执行）
devops prod-deploy --dry-run

# 跳过确认（对于生产环境快捷键）
devops prod-deploy --yes
```

### 管理快捷键

```bash
# 列出所有快捷键
devops shortcut list

# 按标签过滤
devops shortcut list --tags production

# 查看快捷键详情
devops shortcut show prod-deploy

# 编辑快捷键
devops shortcut edit prod-deploy

# 删除快捷键
devops shortcut delete prod-deploy
```

## 🎮 实用场景

### 场景1: 标准化团队部署

```bash
# 团队leader创建标准部署快捷键
devops shortcut save team-java-deploy \
  devops run java my-app \
  --build-version "jdk:17,maven:3.9.3" \
  --service-port "8080" \
  --namespace dev \
  --description "团队Java应用标准部署" \
  --tags "team,standard"

# 团队成员使用（会自动应用团队标准配置）
devops team-java-deploy --override --git-url https://github.com/company/user-service.git
```

### 场景2: 多环境部署

```bash
# 创建不同环境的快捷键
devops shortcut save deploy-dev \
  devops run java my-app --namespace dev --build-env dev \
  --description "开发环境部署" --tags "dev"

devops shortcut save deploy-test \
  devops run java my-app --namespace test --build-env test \
  --description "测试环境部署" --tags "test"

devops shortcut save deploy-prod \
  devops run java my-app --namespace production --build-env prod \
  --description "生产环境部署" --tags "production"

# 快速切换环境部署
devops deploy-dev
devops deploy-test
devops deploy-prod  # 会要求确认
```

### 场景3: 复杂微服务部署

```bash
# 保存各个微服务的部署快捷键
devops shortcut save user-service \
  devops run java user-service \
  --service-port "http:8080,admin:9090,metrics:9091" \
  --export-port "30081,30091" \
  --namespace microservices \
  --tags "microservice,user"

devops shortcut save order-service \
  devops run java order-service \
  --service-port "http:8080,admin:9090,metrics:9091" \
  --export-port "30082,30092" \
  --namespace microservices \
  --tags "microservice,order"

# 快速部署微服务
devops user-service
devops order-service
```

## 🔧 高级功能

### 参数覆盖

快捷键支持灵活的参数覆盖：

```bash
# 原始快捷键
devops shortcut save base-deploy \
  devops run java my-app --namespace dev --build-env dev

# 覆盖命名空间和环境
devops base-deploy --override --namespace production --build-env prod

# 覆盖Git分支
devops base-deploy --override --git-branch feature/new-feature

# 覆盖多个参数
devops base-deploy --override --namespace test --build-env test --git-branch develop
```

### 安全确认

系统会自动识别生产环境相关的快捷键并要求确认：

```bash
# 包含 "prod" 的快捷键会要求确认
devops prod-deploy
# 输出: ⚠️  这可能是生产环境相关的操作
#       是否继续执行？ [y/N]:

# 跳过确认
devops prod-deploy --yes

# 命令中包含 "production" 也会要求确认
devops my-deploy  # 如果命令中有 --namespace production
```

### 预览模式

```bash
# 预览将要执行的命令
devops prod-deploy --dry-run
# 输出: 预览模式 - 不会实际执行命令
#       将要执行的命令: devops run java my-app --build-env prod --namespace production
```

## 📁 存储结构

快捷键存储在工作空间的 `shortcuts/` 目录中：

```
workspace/
├── my-team/
│   ├── config
│   ├── shortcuts/              # 快捷键目录
│   │   ├── prod-deploy.json   # 生产部署快捷键
│   │   ├── dev-deploy.json    # 开发部署快捷键
│   │   └── microservice.json  # 微服务部署快捷键
│   └── README.md
```

### 快捷键文件格式

```json
{
  "name": "prod-deploy",
  "description": "生产环境部署命令",
  "command": "devops run java my-app --build-env prod --namespace production",
  "created_at": "2024-01-01T10:00:00Z",
  "updated_at": "2024-01-01T10:00:00Z",
  "tags": ["production", "java"],
  "workspace": "my-team"
}
```

## 🎯 自动补全

快捷键支持完整的自动补全功能：

```bash
# 补全快捷键名称
devops prod-<TAB>  # 自动补全为 prod-deploy

# 补全快捷键子命令
devops shortcut <TAB>  # 显示: save run list show delete edit help

# 补全快捷键名称（在子命令中）
devops shortcut show <TAB>  # 显示所有可用的快捷键名称
```

## 💡 最佳实践

### 命名规范

```bash
# 推荐的快捷键命名
<环境>-<操作>        # prod-deploy, dev-deploy
<服务>-<环境>        # user-service-prod, order-service-dev
<团队>-<标准>        # team-java, team-vue
```

### 描述和标签

```bash
# 使用有意义的描述和标签
devops shortcut save prod-deploy \
  "devops run java my-app --build-env prod" \
  --description "生产环境Java应用部署，包含完整的安全配置" \
  --tags "production,java,security"
```

### 团队协作

```bash
# 1. 团队leader创建标准快捷键
devops shortcut save team-standard \
  "devops run java app --build-version 'jdk:17,maven:3.9.3'" \
  --description "团队标准Java部署配置"

# 2. 团队成员使用并覆盖特定参数
devops team-standard --override --git-url https://github.com/company/my-service.git

# 3. 定期审查和更新快捷键
devops shortcut list --tags team
devops shortcut edit team-standard
```

## 🛠️ 故障排除

### 常见问题

**快捷键不存在**：
```bash
devops my-shortcut
# 错误：快捷键不存在: my-shortcut
# 使用 'devops shortcut list' 查看可用的快捷键
```

**参数覆盖不生效**：
```bash
# 确保使用 --override 参数
devops my-shortcut --override --namespace test

# 或者直接提供覆盖参数
devops my-shortcut --namespace test
```

**权限问题**：
```bash
# 检查工作空间目录权限
ls -la workspace/my-team/shortcuts/

# 修复权限
chmod 755 workspace/my-team/shortcuts/
chmod 644 workspace/my-team/shortcuts/*.json
```
