## 🆕 最新更新

### v1.9.0 - 离线安装支持
- 新增 `--offline` 参数支持离线安装
- 自动检测DevOps项目目录并使用离线模式
- 自动修复Windows/Linux换行符兼容性问题
- 支持内网环境和无网络连接的服务器部署

### v1.8.5 - 多端口配置
- 新增 `--service-port` 和 `--export-port` 参数
- 支持多端口和命名端口配置
- 智能端口映射和NodePort管理

### v1.8.4 - 交互式部署
- 支持 `devops run -i` 交互式部署
- 智能显示workspace默认值
- 引导式配置体验

### v1.8.3 - Workspace版本配置
- 支持workspace级别的版本配置
- 版本优先级：命令行 > workspace配置

## 📞 获取帮助

- 查看 [故障排除](troubleshooting/) 文档

- 在项目仓库提交 Issue
