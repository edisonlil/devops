# 快速入门指南

欢迎使用 DevOps 工具链！本指南将帮助您在 5 分钟内完成第一次部署。

## 🎯 学习目标

通过本指南，您将学会：
- 安装和配置 DevOps 工具
- 创建第一个工作空间
- 部署第一个应用
- 了解基本的命令和概念

## 📋 前置条件

在开始之前，请确保：
- 已完成 [安装指南](../01-安装指南/安装指南.md)
- 有一个可访问的 Git 仓库
- 了解基本的命令行操作

## 🚀 第一步：验证安装

```bash
# 检查 DevOps 是否正确安装
devops --version

# 查看帮助信息
devops --help
```

如果看到版本信息，说明安装成功！

## 🏢 第二步：创建工作空间

工作空间是项目的配置容器，包含团队的默认设置：

```bash
# 创建工作空间（交互式）
devops create workspace my-project -i

# 系统会引导您配置：
# - 部署平台（Kubernetes/Docker Swarm）
# - Git 仓库地址
# - Harbor 镜像仓库信息
# - 默认命名空间
```

### 非交互式创建

```bash
# 快速创建 Kubernetes 工作空间
devops create workspace my-project \
  --platform KUBERNETES \
  --namespace dev \
  --git-url https://github.com/your-org \
  --set-default
```

## 🎮 第三步：部署第一个应用

### Java 应用部署

```bash
# 交互式部署（推荐新手）
devops run java my-app -i

# 系统会引导您配置：
# 1. Git 仓库地址
# 2. 分支名称
# 3. 构建工具版本
# 4. 端口配置
# 5. 部署环境
```

### 非交互式部署

```bash
# 直接部署 Java 应用
devops run java my-app \
  --git-url https://github.com/your-org/my-app.git \
  --git-branch main \
  --service-port "8080" \
  --export-port "30080"
```

### Vue 应用部署

```bash
# 部署 Vue 前端应用
devops run vue frontend \
  --git-url https://github.com/your-org/frontend.git \
  --service-port "80" \
  --export-port "30080"
```

## 📊 第四步：查看部署状态

```bash
# 查看 Kubernetes 资源
kubectl get pods -n dev
kubectl get svc -n dev

# 查看应用日志
kubectl logs -l app=my-app -n dev --tail=50

# 查看服务状态
kubectl describe svc my-app-service -n dev
```

## 🌐 第五步：访问应用

### 通过 NodePort 访问

```bash
# 获取节点 IP
kubectl get nodes -o wide

# 访问应用
curl http://<node-ip>:30080
# 或在浏览器中打开 http://<node-ip>:30080
```

### 通过端口转发访问

```bash
# 端口转发到本地
kubectl port-forward svc/my-app-service 8080:8080 -n dev

# 本地访问
curl http://localhost:8080
# 或在浏览器中打开 http://localhost:8080
```

您已经成功完成了第一次部署！🎊

## 💡 实用技巧

### 查看工作空间信息

```bash
# 查看当前工作空间配置
devops env info

# 切换工作空间
devops env use another-workspace
```

### 使用模板

```bash
# 查看可用模板
devops template list

# 使用特定模板
devops run java my-app --template spring-boot-advanced
```

### 环境管理

```bash
# 部署到不同环境
devops run java my-app --build-env dev    # 开发环境
devops run java my-app --build-env test   # 测试环境
devops run java my-app --build-env prod   # 生产环境
```

## 🛠️ 常见问题

### 部署失败怎么办？

1. **检查日志**：
```bash
kubectl logs -l app=my-app -n dev
```

2. **检查资源状态**：
```bash
kubectl get pods -n dev
kubectl describe pod <pod-name> -n dev
```

3. **查看事件**：
```bash
kubectl get events -n dev --sort-by='.lastTimestamp'
```

### 无法访问应用？

1. **检查服务配置**：
```bash
kubectl get svc -n dev
kubectl describe svc my-app-service -n dev
```

2. **检查防火墙**：
```bash
# 确保 NodePort 端口未被防火墙阻止
sudo ufw status
```

3. **检查网络连通性**：
```bash
# 从集群内部测试
kubectl run test-pod --image=busybox --rm -it -- sh
wget -qO- http://my-app-service:8080
```
