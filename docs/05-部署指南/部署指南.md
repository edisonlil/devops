# 部署指南

本指南详细介绍如何使用 DevOps 工具链部署各种类型的应用到不同的环境中。

## 🎯 部署概览

DevOps 支持多种应用类型和部署平台：

### 支持的应用类型
- **Java 应用**: Spring Boot、Spring Cloud、传统 Web 应用
- **前端应用**: Vue.js、React、Angular、静态网站
- **Go 应用**: Web 服务、API 服务、微服务
- **容器应用**: 任何可容器化的应用

### 支持的部署平台
- **Kubernetes**: 推荐的容器编排平台
- **Docker Swarm**: 轻量级容器编排
- **单机 Docker**: 开发和测试环境

## 🚀 Java 应用部署

### Spring Boot 应用

```bash
# 基本部署
devops run java my-spring-app \
  --git-url https://github.com/company/my-spring-app.git \
  --service-port "8080" \
  --export-port "30080"

# 生产环境部署
devops run java my-spring-app \
  --git-url https://github.com/company/my-spring-app.git \
  --git-branch release \
  --build-version "jdk:11,maven:3.8.6" \
  --build-env prod \
  --service-port "8080" \
  --export-port "30080" \
  --namespace production
```

### 微服务部署

```bash
# 用户服务
devops run java user-service \
  --git-url https://github.com/company/user-service.git \
  --service-port "http:8080,admin:9090" \
  --export-port "30081,30091" \
  --namespace microservices

# 订单服务
devops run java order-service \
  --git-url https://github.com/company/order-service.git \
  --service-port "http:8080,admin:9090" \
  --export-port "30082,30092" \
  --namespace microservices
```

### Java 配置选项

| 配置项 | 说明 | 示例 |
|--------|------|------|
| `--build-tool` | 构建工具 | `--build-tool maven` |
| `--java-opts` | JVM 参数 | `--java-opts "-Xmx1g -Xms512m"` |
| `--build-version` | JDK/Maven版本 | `--build-version "jdk:17,maven:3.9.3"` |

## 🎨 前端应用部署

### Vue.js 应用

```bash
# 开发环境部署
devops run vue frontend \
  --git-url https://github.com/company/frontend.git \
  --build-version "node:18.12" \
  --service-port "80" \
  --export-port "30080" \
  --build-env dev

# 生产环境部署
devops run vue frontend \
  --git-url https://github.com/company/frontend.git \
  --git-branch main \
  --build-version "node:18.12" \
  --build-env prod \
  --service-port "80" \
  --export-port "30080" \
  --namespace production
```

### 静态网站部署

```bash
# Nginx 静态网站
devops run nginx website \
  --git-url https://github.com/company/website.git \
  --service-port "80" \
  --export-port "30080"
```

### 前端配置选项

| 配置项 | 说明 | 示例 |
|--------|------|------|
| `--build-version` | Node.js版本 | `--build-version "node:18.12"` |
| `--build-env` | 构建环境 | `--build-env prod` |
| `--build-cmds` | 自定义构建命令 | `--build-cmds "npm run build:prod"` |

## 🌍 环境管理

### 开发环境

```bash
# 开发环境特点：
# - 使用最新版本
# - 启用调试功能
# - 资源限制较小

devops run java my-app \
  --build-env dev \
  --build-version "jdk:17,maven:3.9.3" \
  --namespace dev \
  --service-port "8080,9090" \
  --java-opts "-Xmx512m -Xdebug"
```

### 测试环境

```bash
# 测试环境特点：
# - 使用稳定版本
# - 模拟生产配置
# - 完整的监控

devops run java my-app \
  --build-env test \
  --build-version "jdk:11,maven:3.8.6" \
  --namespace test \
  --service-port "8080" \
  --export-port "30080"
```

### 生产环境

```bash
# 生产环境特点：
# - 使用经过验证的版本
# - 优化的资源配置
# - 完整的监控和日志

devops run java my-app \
  --build-env prod \
  --build-version "jdk:11,maven:3.8.6" \
  --namespace production \
  --service-port "8080" \
  --export-port "30080" \
  --java-opts "-Xmx2g -Xms1g -XX:+UseG1GC"
```

## 🔄 部署策略

### 蓝绿部署

```bash
# 部署到绿色环境
devops run java my-app \
  --namespace green \
  --service-port "8080" \
  --export-port "30081"

# 验证后切换流量（手动操作）
# kubectl patch service my-app-service -p '{"spec":{"selector":{"version":"green"}}}'
```

### 滚动更新

```bash
# Kubernetes 默认使用滚动更新
devops run java my-app \
  --git-branch v2.0 \
  --namespace production

# 查看滚动更新状态
kubectl rollout status deployment/my-app -n production
```

### 金丝雀部署

```bash
# 部署金丝雀版本（少量副本）
devops run java my-app-canary \
  --git-branch canary \
  --namespace production \
  --template spring-boot-canary
```

## 📊 部署监控

### 查看部署状态

```bash
# 查看 Pod 状态
kubectl get pods -n production

# 查看部署状态
kubectl get deployments -n production

# 查看服务状态
kubectl get svc -n production
```

### 查看应用日志

```bash
# 查看最新日志
kubectl logs -l app=my-app -n production --tail=100

# 实时查看日志
kubectl logs -l app=my-app -n production -f

# 查看特定 Pod 日志
kubectl logs my-app-xxx-yyy -n production
```

### 应用健康检查

```bash
# 检查应用健康状态
curl http://<node-ip>:30080/health

# 查看应用指标
curl http://<node-ip>:30090/metrics
```

## 🛠️ 故障排除

### 部署失败

```bash
# 查看部署事件
kubectl get events -n production --sort-by='.lastTimestamp'

# 查看 Pod 详细信息
kubectl describe pod <pod-name> -n production

# 查看部署详细信息
kubectl describe deployment my-app -n production
```

### 应用无法访问

```bash
# 检查服务配置
kubectl get svc my-app-service -n production -o yaml

# 检查端点
kubectl get endpoints my-app-service -n production

# 测试服务连通性
kubectl run test-pod --image=busybox --rm -it -- sh
wget -qO- http://my-app-service:8080
```

### 镜像拉取失败

```bash
# 检查 Harbor Secret
kubectl get secret harbor-secret -n production

# 重新创建 Harbor Secret
devops env harbor-secret --namespace production --update

# 检查镜像是否存在
docker pull harbor.company.com/project/my-app:latest
```
