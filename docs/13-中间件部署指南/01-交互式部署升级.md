# 01-交互式部署升级

## 概述

`run_middleware_interactive` 函数已经升级，现在支持：
1. 动态扫描可用的中间件模板
2. 根据模板元数据自动生成交互式配置界面
3. 支持默认值显示和非必填项处理

## 环境要求

### Python版本要求
- **Python 3.6+**: 支持基本功能
- **Python 3.7+**: 推荐版本，支持所有功能

### 依赖包要求
```bash
# Python 3.6 兼容版本
PyYAML>=5.1,<7.0
Jinja2>=2.10,<3.1

# Python 3.7+ 推荐版本
PyYAML>=5.4.1
Jinja2>=2.11.0
```

### 安装依赖
```bash
# 自动安装（推荐）
./bin/install_dependencies.sh

# 手动安装
pip3 install --user PyYAML Jinja2

# 或系统安装
sudo pip3 install PyYAML Jinja2
```

## 新功能特性

### 1. 动态模板选择
- 不再硬编码中间件类型列表
- 自动扫描 `templates/{platform}/middleware/` 目录
- 从 `metadata.yaml` 读取模板描述信息

### 2. 基于元数据的变量收集
- 解析模板的 `metadata.yaml` 文件中的 `variables` 字段
- 支持变量类型：`string`, `integer`, `boolean`
- 支持默认值和必填项配置

### 3. 智能交互提示
- 有默认值的变量显示为：`变量描述 (默认: 默认值): `
- 用户直接回车使用默认值
- 没有默认值的必填项会要求用户输入
- 支持类型验证（整数、布尔值等）

## 使用方法

### 基本用法
```bash
# 交互式选择模板和配置
devops run middleware -i

# 指定模板后交互式配置
devops run middleware redis-standalone my-redis -i
```

## 模板文件结构

### 模板后缀名规范

DevOps中间件部署系统支持多种模板格式，通过文件后缀名进行识别：

| 后缀名 | 模板类型 | 语法 | 用途 |
|--------|----------|------|------|
| `.yaml.j2` | Jinja2模板 | `{{ variable }}`, `{% if %}` | 复杂逻辑、条件渲染（推荐） |
| `.yaml.tpl` | 占位符模板 | `?variable` | 简单变量替换 |
| `.yaml` | 自动检测 | 混合或未知 | 向后兼容 |

系统按优先级查找：`deploy.yaml.j2` → `deploy.yaml.tpl` → `deploy.yaml`

### 模板元数据格式

模板的 `metadata.yaml` 文件需要包含 `variables` 字段：

```yaml
name: "redis-standalone"
type: "redis"
description: "Redis单实例部署模板"
version: "1.0"

variables:
  - name: "memory_limit"
    type: "string"
    default: "512Mi"
    description: "内存限制"
    validation: "^[0-9]+[MG]i$"

  - name: "storage_size"
    type: "string"
    default: "1Gi"
    description: "存储大小"

  - name: "redis_password"
    type: "string"
    default: "auto-generate"
    description: "Redis访问密码"

  - name: "replicas"
    type: "integer"
    default: 1
    description: "副本数量"
    required: true

  - name: "enable_backup"
    type: "boolean"
    default: false
    description: "启用备份"
```

## 变量字段说明

- `name`: 变量名称（必填）
- `type`: 变量类型，支持 `string`, `integer`, `boolean`
- `default`: 默认值（可选，有默认值的变量变为非必填）
- `description`: 变量描述（用于交互提示）
- `required`: 是否必填（可选，默认为 false）
- `validation`: 验证规则（可选，暂未实现）

## 实现的核心函数

1. `list_available_middleware_templates()` - 动态扫描可用模板
2. `parse_template_variables()` - 解析模板变量定义
3. `collect_template_variables()` - 收集用户输入
4. `generate_middleware_command()` - 生成部署命令预览
5. `confirm_and_execute_middleware()` - 确认并执行部署

## 向后兼容性

- 保持原有的命令行参数支持
- 非交互式模式不受影响
- 现有模板无需修改即可工作（使用系统默认值）
